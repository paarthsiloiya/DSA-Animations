Bellman-Ford Algorithm

Bellman-Ford computes shortest paths from a single start vertex — and, unlike Dijkstra, it tolerates negative edge weights. Its engine is edge relaxation: for an edge $u \rightarrow v$ of weight $w$, whenever dist[u] + w < dist[v], vertex $v$'s tentative distance improves. Repeating the pass over every edge for $V-1$ rounds guarantees every shortest path (which uses at most $V-1$ edges) has been fully propagated.

Why Exactly V−1 Rounds?

A shortest path without cycles visits at most $V-1$ edges. After round $k$, every shortest path using $\le k$ edges is guaranteed correct — one more edge of the path becomes provable per round. $V-1$ rounds therefore cover every possible path length. This is also why the algorithm survives negative weights: it never commits greedily, it just keeps improving until the arithmetic settles.

Negative-Cycle Detection

The standard algorithm ends with a V-th pass: if any edge can still be relaxed after $V-1$ rounds, distances can still improve — which is only possible when the graph contains a negative-weight cycle reachable from the start (you can loop through it forever, driving the distance to $-\infty$). The code on the right shows it as the final commented pass; the video covers the relaxation rounds only. On this demo graph the V-th pass finds nothing to relax — all distances are stable, so no negative cycle is reachable from vertex 0 — the negative edges here sit only on cycles that are positive overall (e.g. the loop $1 \rightarrow 5 \rightarrow 2 \rightarrow 1$ sums to $2 + (-2) + 1 = 1 > 0$).

Complexity: $V-1$ rounds × $E$ edge relaxations each — $O(V \cdot E)$ time, $O(V)$ space (the distance array; the edge list is the input itself). Best case still runs all rounds — the loop count is fixed, only the work per edge varies.

Must know: Dijkstra is faster on non-negative graphs ($O((V+E)\log V)$ with a heap), but only Bellman-Ford (of the two) can be trusted when weights go below zero. For all-pairs, see Floyd-Warshall.
