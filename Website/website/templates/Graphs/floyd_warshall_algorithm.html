Floyd-Warshall Algorithm

Floyd-Warshall solves the all-pairs shortest path problem: shortest distances between every ordered pair of vertices in one dynamic-programming pass — with negative weights allowed, detecting negative cycles via the diagonal.

The DP Formulation

Let $d^{(k)}[i][j]$ = the shortest path from $i$ to $j$ using only vertices $\{0, \dots, k-1\}$ as intermediates. Then:

$d^{(k+1)}[i][j] = \min\big(d^{(k)}[i][j],\; d^{(k)}[i][k] + d^{(k)}[k][j]\big)$

Either vertex $k$ doesn't help (keep the old distance), or the best route splits at $k$: best-known $i \rightarrow k$, then best-known $k \rightarrow j$. The base case $d^{(0)}[i][i] = 0$, $d^{(0)}[i][j] = w(i,j)$ for direct edges, $\infty$ otherwise. After allowing all $V$ vertices as intermediates, $d[i][j]$ is the true shortest distance. The in-place triple loop works because $d[i][k]$ and $d[k][j]$ are already correct for the first $k$ intermediates when row/column $k$ is read.

Complexity and the Negative-Cycle Note

  • Time: $\Theta(V^3)$ — three nested loops over $V$, unconditional: best = worst = average. Cheap for the all-pairs question on small $V$, hopeless for large sparse graphs (there, $V$ runs of Dijkstra usually win).
  • Space: $\Theta(V^2)$ — the distance matrix itself (the predecessor/next matrix for path reconstruction adds another $V^2$).
  • Negative cycles: the algorithm tolerates negative edges (as this demo shows) but a negative diagonal after the loops ($d[i][i] < 0$) reveals a negative cycle through vertex $i$. Here the diagonal stays all zeros — the negative edges feed forward, never back, so no cycle.

Must know: Floyd-Warshall is for dense all-pairs; for a single source use Dijkstra (non-negative) or Bellman-Ford (negative-safe, $O(VE)$), and re-run per source.
