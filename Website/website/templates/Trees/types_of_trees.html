Types of Trees

A tree is a hierarchical structure of nodes connected by edges, where one node is designated the root and every other node has exactly one parent. Trees have no cycles and no node is unreachable from the root — which is why they model file systems, organisation charts, parse trees, and the decision structures behind many algorithms.

The Vocabulary of a Tree

  • Root: the node with no parent — the single entry point of the tree. Every other node can be reached from it by following edges downward.
  • Parent / Child: an edge connects a parent node to each of its children. Node D is the parent of I and J in the animation below.
  • Siblings: nodes that share the same parent — F, G and H are siblings because they are all children of C.
  • Leaf: a node with no children.
  • Subtree: any node together with all of its descendants — every tree node is the root of its own subtree.
  • Depth / Height: the depth of a node counts edges from the root down to it; the height of a tree is the maximum depth over all nodes. A one-node tree (just a root) has height 0.

The animation below builds an 11-node tree and labels each of these roles, then shows the two operations that change a tree's shape — insertion and deletion — and what happens when a whole subtree is cut loose.

What the animation shows: the tree A–(B, C), B–(D, E), C–(F, G, H), D–(I, J), E–(K) is drawn in one pass, then each role is labelled in turn: B as a Node, A as the Root Node, D as a Parent Node and I as its Child Node, F, G, H together as Siblings, D, I, J together as a Subtree, and F, G, H, I, J, K as the Leaf Nodes. A new node L is then inserted under G (one new edge — that is the entire insert), leaf K is deleted (removing its single edge), and finally the edge A–B is cut, splitting the structure into two trees — a forest.

Tree Taxonomy — How Many Children per Node?

The demo tree above is a general tree: a node may hold any number of children — node C has three. Restricting that freedom gives the families most algorithms use:

  • General tree — no limit on children per node. File-system directories and organisational charts are general trees.
  • Binary tree — every node has at most two children, a left and a right child. This is the workhorse family: heaps, binary search trees, expression trees and the recursion trees of divide-and-conquer algorithms are all binary. The in-order / pre-order / post-order animations run on a binary tree.
  • Ternary tree — at most three children per node, for example a ternary search trie with low / equal / high branches.
  • Ordered tree — children of each node have a defined order (left before right), which is what makes traversal orders and binary search trees meaningful.

Two special shapes appear again and again: a complete tree fills every level except possibly the last, left to right — the shape heaps and the list representation rely on — and a balanced tree keeps the height of the two sides of every node close, the property self-balancing search trees such as AVL trees maintain to guarantee $O(\log n)$ operations.

Complexity of the Basic Operations

  • Insert a child: writing one new edge — $O(1)$ when you hold the parent node, as the animation shows with node L. Best, worst and average agree: it is a single pointer write.
  • Delete a node: detaching a leaf costs $O(1)$; detaching an interior node removes its whole subtree, costing $\Theta(s)$ where $s$ is the subtree size (every descendant is affected). Deleting the root orphans the entire rest of the tree.
  • Find / reach a node: no index exists — reaching a node means walking from the root, costing $O(h)$, where $h$ is the tree height: $O(1)$ best (the root), $O(n)$ worst (a degenerate chain), $O(\log n)$ when the tree is balanced.
  • Space: a tree of $n$ nodes stores $n$ nodes and exactly $n-1$ edges — every node except the root is pointed to once — so the structure costs $\Theta(n)$.

Must know: a tree with $n$ nodes always has $n-1$ edges — count the edges in the animation as nodes appear. Removing one edge never leaves a node stranded; it produces exactly one more tree (that is the forest at the end of the video).
